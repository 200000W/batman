# The Dark Knight — A Christopher Nolan Film Tribute

A premium, highly interactive fan tribute website dedicated to Christopher Nolan's *The Dark Knight Trilogy*. The application features a dark, cinematic UI representing the Batcave/Batcomputer aesthetic.

Live Demo: **[https://200000W.github.io/batman/](https://200000W.github.io/batman/)**

## Key Features
- **Cinematic Landing (Hero)**: Dual-image canvas reveal system showing the iconic Dark Knight silhouette behind a dynamic mouse-interactive spotlight trail over Gotham City.
- **The Legend (Trilogy)**: Gritty, hover-responsive card designs for the three films (*Batman Begins*, *The Dark Knight*, *The Dark Knight Rises*).
- **Words of Gotham (Quotes)**: Famous character quotes with custom typography and elegant borders.
- **Batcave Database (Gallery)**: Interactive dossier layout styled as a Batcomputer terminal, showcasing classified status files and custom portraits of major characters (Batman, Joker, Two-Face, Ra's al Ghul, Bane, Catwoman) complete with scan-lines and active statuses.
- **Developer Credit**: Styled developer badge reading "Developed by Mr. Z" in the footer.

## Tech Stack
- **Framework**: React 19 + Vite 8
- **Styling**: Vanilla CSS (CSS variables, flexbox/grid layout, typography styling)
- **Animations**: Framer Motion
- **Interactions**: HTML5 Canvas API

## Getting Started

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/200000W/batman.git
   ```
2. Navigate to the project directory:
   ```bash
   cd batman/vite-project
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally
To launch the local development server:
```bash
npm run dev
```

### Deployment to GitHub Pages
To compile the production build and publish directly to the `gh-pages` branch:
```bash
npm run deploy
```
